$$p(x\mid\lambda) = \mathrm{Poisson}(x\mid\lambda) = \frac{\lambda^x e^{-\lambda}}{x!}$$ où $\lambda$ est le paramètre de moyenne. Support : $\Omega_X = \mathbb N = {0,1,2,\dots}$.

Souvent utilisée pour modéliser des **données de comptage** (« count data »).

## Propriétés

$$E[X] = \lambda, \qquad \mathrm{Var}[X] = \lambda$$
