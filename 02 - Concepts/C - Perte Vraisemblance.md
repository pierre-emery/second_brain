$$\widehat R (f) = - \frac 1 N \sum_{i=1}^N \log p(y_i|f(x_i))$$

## Idée

Minimiser cette perte revient à maximiser la [[C - Vraisemblance]] des données observées sous le modèle. Le modèle qui explique le mieux les données obtenues.
