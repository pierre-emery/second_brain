## Définition

Compromis entre la précision et la complexité du modèle choisi.

- Choisir le minimum de paramètres sans perdre trop d'information (même idée que les méthodes de [[C - Réduction de dimensions]])

## Rasoir d'Occam

Le modèle le plus simple qui explique bien les données est le meilleur. Pour obtenir un meilleur ajustement, on peut aussi prendre un modèle expressif et le régulariser plutôt que le complexifier directement.
