## Définition

Un système/modèle reproduit ou amplifie des inégalités déjà présentes dans les données utilisées pour l'entraîner.

## D'où vient le biais

- Les données sont collectées par des personnes (biais humain)
- Certains groupes apparaissent plus souvent que d'autres dans les données
- Certains groupes ont un accès inégal aux systèmes qui génèrent les données (ex: seules les personnes avec plus de moyens utilisent davantage un service en ligne)

## Équité

- Comprendre les effets de ces problèmes sur les décisions du modèle
- Rendre le modèle et les données plus équitables
- Éviter d'amplifier des biais historiques déjà présents dans la société

## Exemple

Des systèmes utilisés pour prédire le risque de récidive criminelle ont été critiqués pour être significativement biaisés contre certains groupes raciaux, alors qu'ils étaient entraînés uniquement sur des données historiques jugées "neutres".
